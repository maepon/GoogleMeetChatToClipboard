## 2. TC-1.7 同一メンバー連続発言抽出テスト結果

### 不具合の確認 (修正前)
- **修正前の実測**: 同一メンバーが連続して発言（例：「相手の送信1」「相手の送信2」）した場合、1件目のメッセージしかコピーされず、2件目以降が抽出漏れしていた。
- **原因**: 1つのメッセージ親ブロック `div.Ss4fHf[jsname="Ypafjf"]` 配下に複数の `div.RLrADb` レコードが存在する構造において、`querySelector` により1件目の本文しか取得していなかった。

### 修正後の検証結果 (修正後)
- **修正内容**: `querySelectorAll(selectors.messageText)` に改修し、親ブロック内のすべての発言メッセージをループ抽出。
- **実測結果**: 提出された `att_002/dom.txt` の実機データにおいて、全 8 件の連続発言メッセージが漏れなく、正しい順序かつ重複なく抽出されることを確認。
